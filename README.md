# Nexo Legal

Landing page de um escritório de advocacia fictício, criada para estudo
de desenvolvimento web e para compor meu portfólio.

O projeto utiliza Next.js, TypeScript e Tailwind CSS.

## Como rodar localmente

1. Instale as dependências com `npm.cmd install`.
2. Inicie o servidor com `npm.cmd run dev`.
3. Abra http://localhost:3000.

Os comandos acima funcionam no PowerShell do Windows. No macOS ou Linux,
use `npm` no lugar de `npm.cmd`.
